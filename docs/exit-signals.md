# 出場：自己帶 AI 做出來

進場有到價通知了。**出場這一段沒有標準答案，由你自己帶 AI 做。** 老師只給三個方向；每個方向，你要先回答「規格問題」，AI 才知道要做什麼。

> 買進靠計畫，賣出靠紀律。出場規則寫不清楚，AI 做出來的只是另一個猜測。

## 先想清楚：你要的是哪一種出場？

| 類型 | 問自己 |
|---|---|
| 停損 | 進場理由錯了，在哪裡認錯？（交易計畫已寫停損價） |
| 停利／減碼 | 漲到哪裡，賣壓會變大？ |
| 轉弱 | 什麼跡象代表買盤走了？ |

下面三個方向都屬於「停利／轉弱」。選一個開始，做完再加第二個。

---

## 方向一：爆量黑K

**股票邏輯**：漲了一段後，某天成交量突然放大，收盤卻比開盤低，代表有人趁高檔大量賣出。

**規格問題（先自己回答）**

1. 「爆量」是跟什麼比？前 5 日均量？20 日均量？幾倍才算？
2. 「黑K」只要收盤 < 開盤，還是實體要夠長？跌幅要多少？
3. 位置重要嗎？要在漲多之後、或接近前高時才算？
4. 盤中看到就通知，還是收盤確認才算？（盤中量還沒走完）
5. 出現之後：全部出場、出一半，還是只提醒？

**需要的資料**：日K的開高低收與成交量（雪鴞日 K 就有）。

---

## 方向二：可轉債轉換價

**股票邏輯**：公司有發可轉債時，股價超過**轉換價**，債券持有人換成股票就有賺，可能轉換後賣出；股價漲到轉換價的一定倍數，公司可能啟動提前贖回，逼持有人轉換。轉換價附近常是籌碼的關鍵價位。

**規格問題（先自己回答）**

1. 你的股票有沒有發行中的可轉債？轉換價多少、到期日何時？
2. 轉換價會因除權息、增資而調整，你用的是不是**最新**轉換價？
3. 你要看的是「站上轉換價」，還是「轉換價的某個倍數」？為什麼是這個倍數？
4. 同一家公司有好幾檔可轉債時，看哪一檔？
5. 碰到之後，你的動作是什麼？

**需要的資料**：可轉債基本資料（轉換價、發行與到期日），官方來源是櫃買中心與公開資訊觀測站。先確認資料日期，不要用記憶中的轉換價。

---

## 方向三：前高壓力

**股票邏輯**：價格回到前一波高點附近，當時沒賣到的人想解套，賣壓會出現。

**規格問題（先自己回答）**

1. 「前高」是哪一段？近 60 日最高？前一個波段高點？怎麼讓程式找到？
2. 「碰到」是盤中最高價碰到，還是收盤接近？接近要差幾 %？
3. 碰到後站上去，是出場訊號還是突破訊號？你怎麼分辨？（想想跟進場的「突破 ≥」怎麼不打架）
4. 碰到時有沒有量的條件？

**需要的資料**：日K最高價；前高的計算要只用**當時已經知道**的資料。

## 動手：交給 AI 的指令（範本，自己改）

```text
請讀 AGENTS.md、docs/price-alerts.md 和 docs/exit-signals.md。
我要做自己的出場訊號，先做「＿＿＿」這一個方向。
我的規格是：
- 定義：＿＿＿
- 資料：＿＿＿（來源與資料日）
- 判斷時間：盤中／收盤後
- 觸發後的動作：＿＿＿
先畫出輸入、處理、輸出、驗收四格，等我確認後再寫程式。
用我收藏裡的股票，找出歷史上符合與不符合的例子各兩個給我核對。
通知沿用 scripts/telegram_notify.py 與 .local/telegram.env，不要讀取或回顯 Token。
不要改進場的到價通知，不要加自動下單。
```

## 驗收：怎樣才算做完

1. 規格問題都有寫下答案，AI 做的跟你寫的一致。
2. 至少各兩個「符合」與「不符合」的歷史例子，你看圖核對過。
3. 資料不足時顯示「不足」，不是當成沒訊號。
4. 用模擬資料送出一則出場通知，手機收到。
5. 寫下這條規則**什麼時候會失效**。

做完一個方向，存成自己的筆記，再挑下一個。三個都做完，就是你自己的出場系統。
