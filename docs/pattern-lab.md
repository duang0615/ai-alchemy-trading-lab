# 型態選股實作：看圖、寫規格、修改後再核對

[K線型態](https://duang0615.github.io/ai-alchemy-trading-lab/stock-picker/patterns.html?mode=candles) · [走勢型態](https://duang0615.github.io/ai-alchemy-trading-lab/stock-picker/patterns.html?mode=shapes) · [自訂繪圖](https://duang0615.github.io/ai-alchemy-trading-lab/stock-picker/patterns.html?mode=custom)

## 三個功能各解決什麼問題

| 我想做的事 | 操作 | 實際使用的資料 |
|---|---|---|
| 找一種K線組合 | 選29種K線之一，設定最新1根或最近3／5／10根 | 雪鴞開、高、低、收，依明確比例判斷 |
| 找接近W底、圓弧底等走勢 | 選19種輪廓之一，設定K棒數與相似門檻 | 最近N根收盤，與示意輪廓比對 |
| 找自己想要的走勢 | 命名、畫線、存檔，再執行 | 使用自己的輪廓與設定 |

本版公式為自行定義的可核對規格，來源網站未公開的辨識公式沒有視為已知。原站參考頁：[K線型態](https://tw.stock-digger.com/candlesticks-patterns)、[型態選股](https://tw.stock-digger.com/pattern-selection)。圖例是輪廓示意，候選K線圖才是雪鴞實際資料。

## 休息練習A：十字線條件怎麼改（10分鐘）

1. 開K線型態頁，選「十字線」，保持日線與最新1根，保存候選數與資料範圍。
2. 展開「修改K線規格」。假設：「把實體上限由全長10%縮到5%，可以只保留開收更接近的股票。」
3. 只改十字實體上限，再跑十字線。挑一檔保留、一檔消失，核對 `abs(收−開)/(高−低)`。
4. 不變動其他參數，保存Markdown。四價相等另有獨立規則，高低相同不能硬除以零。

## 休息練習B：畫自己的W底（10分鐘）

1. 開走勢型態頁，日線、60根、門檻80%，跑W底。
2. 寫假設，再只將門檻改成90%。名單為零也保留，先看輪廓差在哪裡。
3. 開自訂頁，新增「我的W底」。可直接畫線，或載入W底範例後調整一個點。
4. 保存、執行，選一檔看黃色輪廓與實際K線差異。黃色線不代表未來路徑。
5. 匯出型態JSON與Markdown；重開頁面確認已保存。將JSON給另一台電腦時，用「匯入型態JSON」。

繪圖板支援滑鼠拖曳、觸控和鍵盤。用左右鍵選點，上下鍵改高度；全螢幕可用Esc離開。刪除型態後可立即復原，長期保存請匯出JSON。瀏覽器清除網站資料會移除本機型態與筆記。

## 相似分數到底怎麼算

每條收盤曲線和輪廓都以線性插值重採樣為60點，各自換算到0～1，計算均方根差：

`相似度 = 100 × max(0, 1 − sqrt(mean((實際[i] − 輪廓[i])²)))`

價格高低與整體振幅會被移除，形狀的時間對齊會影響分數。沒有使用DTW、自動尋找轉折點或驗證頸線突破。80%表示此公式的分數，不是有80%機率獲利。一字形底的模板是平線，另用 `100 × max(0, 1 − 收盤振幅/(平均收盤×5%))`，80分對應振幅不超過平均收盤1%。

K線的多根分類中，上升／下降三法採5根。鎚頭、倒鎚頭、流星的前期方向採前5根收盤首尾比較，不是已驗證的完整趨勢模型。

## 本版操作證據

2026-10-02、本機2,342檔（含興櫃）：日線60根W底門檻80%找到64檔，門檻90%找到0檔；34檔因資料不足無法比對。最新日鎚頭線40檔。週線60根W底3檔，月線24根W底3檔，月線只到已完成的2026年9月。這些是本次候選數，不是策略績效。

型態公開頁有18檔（原16檔加兩檔事後挑選的輪廓例子），結果與本機不同。缺值與資料不足不當作符合；資料範圍是目前股票清單，包含興櫃。最低成交量篩選使用最新日的張數，即使形狀選的是週／月線也一樣，並在規格中標示。

## 用自己的資料啟動

在學生專案根目錄執行，將路徑改成自己的雪鴞環境：

```powershell
# 若尚未建立候選資料，先執行這行
& 'C:\AI\owl\.venv\Scripts\python.exe' -X utf8 .\stock-picker\build_data.py --env 'C:\AI\owl\.env'
& 'C:\AI\owl\.venv\Scripts\python.exe' -X utf8 .\stock-picker\build_patterns.py --env 'C:\AI\owl\.env'
& 'C:\AI\owl\.venv\Scripts\python.exe' -X utf8 .\stock-picker\serve.py
# http://127.0.0.1:8766/patterns.html?mode=candles
```

第一次本機頁會讀取全範圍的歷史，載入比公開18檔稍久。本機歷史只在`.local`；型態公開頁僅有固定18檔的比例換算教學資料。資料不是即時報價。更新時依序重跑資料程式，重整頁面，核對資料日與範圍。

```text
我的假設是把門檻改成90%會保留輪廓更接近的股票。
只改相似門檻，核對一個保留、一個消失或零候選的例子。

把假設、規格、改前改後、反例與下一步存成Markdown。
```

## 模塊分工

| 檔案 | 職責 |
|---|---|
| `build_patterns.py` | 雪鴞OHLC資料與教學樣本 |
| `pattern-catalog.json`／`make_pattern_catalog.py` | 型態規格、名稱、示意輪廓 |
| `pattern-engine.js` | 唯一計算來源，週月合併、K線與形狀比對 |
| `patterns.html`／`patterns.css`／`patterns.js` | 畫面、繪圖、候選、紀錄與匯出 |
| `test_patterns.cjs` | 零分母、缺值、期間截止與輪廓尺度等測試 |

改規則要同步更新規格，並執行 `node --test stock-picker/test_patterns.cjs`。新增完整交易策略時仍先寫進出場、部位、成本與歷史資料可得時間，再使用雪鴞 `api.bt`。本型態頁沒有新增回測或下單功能。

型態公開例子另加入3707、7921：2026-10-02的W底60根、80%門檻選中，90%未選中。公開18檔名單中是2檔減為0檔。這是事後挑選以演示輪廓修改的案例，不作無偏績效評估。
