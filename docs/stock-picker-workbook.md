# 雪鴞選股實作室：拆解、核對、修改

上一堂學會用 AI，這一堂學會帶 AI 把事情做完。

[開啟完成版](https://duang0615.github.io/ai-alchemy-trading-lab/stock-picker/) · [下載學生專案](https://github.com/duang0615/ai-alchemy-trading-lab/archive/refs/heads/main.zip)

## 先抄答案，再換成自己的需求

這個版本只保留12個雪鴞可以計算的策略與7個資料分頁。`stock-picker/presets.json` 寫明每條條件，`rules.py` 負責純計算，`build_data.py` 負責雪鴞資料，`app.js` 負責畫面。改畫面不必重寫公式。

GitHub Pages 是16檔真實教學樣本的快照，非全市場即時選股。排行榜也只在這16檔內排名。本機版才掃描自己帳號的股票資料。行情是盤後資料，財報與營收的會計期間不能當公告時間。個別公司資料不足仍顯示「資料未提供」，篩選時不把缺值補成零。

## 休息實作一：自己的波段候選池（10分鐘）

1. 開啟完成版，按「多頭排列」。記下範圍、資料日與候選數。
2. 找6533，逐項看MA5、10、20、30、60。先確認此日的結果，不問AI是否一定會漲。
3. 寫假設：「我希望少看量太小的股票，追加最低2000張可能縮小候選。」
4. 按設定，追加最低量2000張，再套用。記錄哪些股票離開，選一檔核對張／股單位。
5. 表格改成圖表，查看日籌碼與財報。選股條件不會自動變成進出場訊號。
6. 下載Markdown，放進上一堂的Obsidian。零候選也保存，不為了選到股票而任意放寬。

給AI：

```text
請讀取 AGENTS.md、skills/snowyowl-picker-lab/SKILL.md。
我的風格是波段。我先用多頭排列，再追加最低成交量2000張。
先說明每個条件的來源、欄位、單位與資料時間，核對6533的一筆資料。
保留原版，只改最低成交量這一項，記錄候選變化與反例。
如果資料缺少，請留下缺口，不要自己補數字或改資料源。
完成後把規格、變更與核對證據存成Markdown。
```

## 休息實作二：從強勢股到自己的交易計畫（10分鐘）

1. 選「相對強勢放量」或「最近收盤創新高」。這是量化某一種強勢的例子，不代表完整產業研究。
2. 用自己的知識庫補上產業方向、消息來源與適用週期。強勢族群是研究入口，個股要另核對價格、流動性與風險。
3. 選一檔候選，寫完下面這張卡。不知道的就標「待定」，不能請AI自動當作老師規則。
4. 回到已有的動能研究頁，找一筆成功與失敗。對照是選股假設錯、規則翻譯錯、資料時間錯，還是成交／出場不同。
5. 把修正假設交給AI，只改一個模塊。這次先寫可驗證規格，正式重跑時用雪鴞api.bt，保留原結果。

| 我要決定的事 | 我的答案 |
|---|---|
| 股票、交易週期、策略版本 | 待填 |
| 為什麼納入候選／來源 | 待填 |
| 何時產生訊號／何時能知道資料 | 待填 |
| 買進觸發、訂單與預計成交時點 | 待填 |
| 跳空或無法成交怎麼處理 | 待填 |
| 什麼條件代表原判斷失效 | 待填 |
| 停損、獲利或時間出場 | 待填 |
| 資金、單筆風險、部位與交易成本 | 待填 |
| 下一次檢查時間／放棄條件 | 待填 |

給AI：

```text
我已有候選股，但還沒有完整交易規則。
請依上表逐項協助我定義，區分來源策略、我的認知、未知和教學假設。
用一個符合例子、一個不符合例子、一個缺資料例子，檢查條件能否執行。
每次只處理一個模塊。完成進出場、部位、成本與公告時間規格後，才安排api.bt。
看到結果後先列證據和原因，再提出只改一項的下一版假設。
不要把回測最高報酬當成唯一驗收標準。
```

## 用自己的雪鴞資料跑

同學使用已有試用包的Python。以下路徑換成自己的安裝位置。

```powershell
& 'C:\AI\owl\.venv\Scripts\python.exe' -X utf8 .\stock-picker\build_data.py --env 'C:\AI\owl\.env'
& 'C:\AI\owl\.venv\Scripts\python.exe' -X utf8 .\stock-picker\serve.py
# 開啟 http://127.0.0.1:8766/
```

資料寫入被Git忽略的`.local/stock-picker-data.json`。服務只綁本機，帳密不送到前端。重新更新資料須再次執行第一行。不要用file://直接開啟，瀏覽器會限制讀取JSON。公開網頁不連同學電腦，也不共用老師帳號。

## 看結果後怎麼改

| 看到的現象 | 先核對 | 接著可測的一項修改 |
|---|---|---|
| 候選太多 | 排名是否只在小樣本內，週期是否吻合 | 追加自己的最低量 |
| 候選為零 | 日期、缺值、比較符號、張／股 | 確認資料後才研究門檻 |
| 不同電腦名單不同 | 更新時間、股票範圍、規格版本 | 固定相同條件與日期再比較 |
| 選到強勢股仍然虧損 | 觸發與成交差別、跳空、出場與成本 | 固定其他條件，只測一種出場 |
| 加條件後回測漂亮 | 是否偷看未來、過度調參、樣本偏差 | 保留樣本外與失敗案例 |

每次留下：來源、版本、假設、改哪裡、實際證據、沒有完成的事、下一步。AI存檔需有實際檔案與路徑；Dify自動寫入須另設串接，不因提到Dify就已自動保存。
