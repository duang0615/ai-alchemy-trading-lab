# 兩次休息都能動手：每次約10分鐘

## 第一次：交易解剖

老師先問：「6533這兩筆都符合相同規則，為什麼一筆賺、一筆賠？」

1. 開啟實作頁，选择6533、時序保留段。
2. 學生先看訊號，再找次日成交，辨認還原價、成本与強制期末出場。
3. 請AI讀取完整逐筆CSV，核對19筆，不只看最好的一筆。
4. 筆記填三句：我原先相信什麼／結果說了什麼／還缺什麼證據。下載放進Obsidian。

驗收：能指出「符合規則仍虧損」与「這筆成功受期末清倉影響」，並指出去掉最佳三筆后會轉負。

## 第二次：模塊改造

老師先問：「我多加一個條件，是變準了，還是只少做幾筆？」

1. 學生先写假設，只选成交量、20MA、持有天數或成本其中一個。
2. 用完成版比較表立即確認；有雪鴞環境的學生再交AI重跑。
3. 比對報酬、回撤、交易數与成本；成功、無效、變差全都保留。
4. 請AI寫工作紀錄：改哪裡、预期、結果、未知、下次怎麼做。每則註明來源与驗證狀態。

驗收：指出新增規則究竟改变哪些交易。3037兩個濾網沒改變結果是有效答案；不能因不漂亮就刪除。

## 放回整堂課的位置

買進判斷收集 → 確認自己的投資喜好 → 知識來源与Obsidian → 拆自己喜歡的軟體 → 規則卡与模塊 → **第一次交易解剖** → 正確回測与成本 → **第二次模塊改造** → 進度、續工与知識補強 → 回答同一檔現在是否符合自己的條件。

知識庫先沿用Obsidian；Dify是日後資料量／多人／檢索工作流的進階選項，不是本實作前置條件。AI寫Markdown、學生核對再存入庫，不必手抄。AI會寫紀錄，不代表已完成Dify自動串接。

## 給AI的續工單

```text
我現在在【交易解剖／模塊改造】。
已完成：
驗收證據（檔案与核對結果）：
目前缺少：
下一步只做：
完成後更新progress.json与resume.md，把驗證過与未驗證分開。
```

頁面筆記与進度是本機資料；此版未串Telegram、背景排程或Dify。環境冷卻／額度恢復時需依续工單接續，不會因等了五小時自动恢復。
