## 已观察的結構

18張策略卡，深色三欄卡片／列表，每張顯示條件與策略名稱。董監改選額外展開3條。選股結果有表格／圖表、設定、收藏和10類分頁。表格日均線、週均線、籌碼、營收、風險、價值與財報。漲幅原站結果顯示5檔，不足以证明其全市場排名、帳號限制或更新機制。

本版提供18張卡、展開、卡片／列表、AND／OR組合、排序、表格／圖表、個股詳情、收藏、設定、候選CSV、Markdown實作紀錄。圖表為基期100的收盤趨勢，非原站K線。收藏與筆記為本機瀏覽器儲存。沒有原站帳號、付費、盤中報價或多裝置同步。

## 不是一模一樣的七組公式

| 項目 | 原站可見的問題 | 本版明示定義 |
|---|---|---|
| 新高 | 未說收盤／最高價、相同高點 | 收盤嚴格突破之前59日高點，近5日有一次 |
| 爆大量 | 無參數5倍、2000000張疑似單位問題 | 前20日均量5倍、最低2000張 |
| 主力悄悄進場 | 每一大戶還須占股本1% | 400張以上集保人數合計，不聲稱具有原站1%篩選 |
| 投信鎖單 | 描述漲幅與條件MACD相衝突 | 依描述：投信3天200張、3日涨幅5% |
| 盤整箱形 | 振幅分母與均量是否含當日未知 | 低點分母、均量含當日 |
| 相對強勢 | 差值／比值口徑未知 | 與加權報酬差10個百分點 |
| 營收成長 | 平均YoY或加總同比未知 | 3月營收加總同比；60月完整序列 |

這些規則可執行且可改造，但沒有與原站全部名單一致的證據。多頭排列按條件列5/10/20/30/60，沒有加描述中的3日線。
