# 進場到價通知與出場作業

先定位學生專案，讀 `AGENTS.md`、`docs/price-alerts.md`、`docs/exit-signals.md`。安裝一定要照 AGENTS.md 的「安裝注意事項」；學生看不到收藏或 Telegram 設定，先依第 6 點更新與重開，不要自己補做設定頁。

## 進場（已完成的功能，帶學生用）

1. 啟動 `python -X utf8 stock-picker/serve.py`，開 `http://127.0.0.1:8766`；公開完成版不能存 Token。
2. 學生自己在「我的收藏」填 Bot Token 與頻道並按「存到本機」。AI 不讀、不印、不要求貼出 `.local/telegram.env`。頻道要先把 Bot 設為管理員。
3. 帶學生替每檔收藏寫進場條件（突破 ≥／回到 ≤）、進場價、停損價與理由。理由要對應選股或型態，不替學生決定價格。
4. 先 `scripts/price_alert.py --fake-price 代號=價格` 模擬；學生確認收到後才盤中執行。查價間隔不得低於 300 秒、同時最多 20 檔。
5. 觸發只通知一次；傳送失敗標「傳送狀態不明」，先看手機再重新監看，不盲目重送。

## 出場（學生自己做，AI 不先給答案）

1. 學生選一個方向。先逐條問 `docs/exit-signals.md` 的規格問題，學生回答前不寫程式、不替他填門檻。
2. 學生回答後，畫輸入→處理→輸出→驗收，確認再實作；建議新檔（例如 `scripts/exit_alert.py`），不改 `price_alert.py` 的進場邏輯。
3. 只用當時已知資料；可轉債轉換價要查官方最新資料與日期，不用記憶值。缺資料顯示「不足」。
4. 提供符合與不符合的歷史例子各至少兩個讓學生核對；通知沿用 `telegram_notify.py`。
5. 不加自動下單。到價或出場通知都是提醒。
